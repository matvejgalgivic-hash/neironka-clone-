# Clone

## Функции

- один экземпляр приложения: повторный запуск возвращается к открытому окну;
- список чатов слева и автоматическое сохранение истории в `%APPDATA%\MyNeuralNet\history.json`;
- краткая память обновляется после четырёх обменов сообщениями и используется вместе с последними репликами;
- переключатель «Размышление» включает или скрывает блок `<think>`; в выключенном режиме отправляется команда `/no_think`;
- чат настроен на помощь с программированием на разных языках;
- контекст модели уменьшен до 3072 токенов для снижения расхода памяти, а обычные ответы ограничены 320 токенами; запросы на код получают больший лимит. Веса модели не меняются.
- режим без размышлений использует ChatML и `/no_think`, чтобы модель сразу переходила к ответу.
- удаление чата работает по его ID, а не по перемещаемому номеру строки в списке.
- новый чат можно создать и чат можно удалить, пока модель генерирует ответ; ответ привязан к своему чату и не попадёт в другой диалог;
- Ctrl+V вставляет текст из буфера в поле ввода; Ctrl+C копирует выделенный текст из ввода или переписки.

## Сборка

Нужны Python 3.12 x64 и зависимости из `requirements.txt`. Модель GGUF и библиотеки уже лежат в `_internal`. Запусти `build.ps1`; он обновит `Clone.exe` и `_internal` в этой же папке.

Не перемещай exe отдельно от папки `_internal`.
